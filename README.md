# akubisa
adalah aplikasi pembelajaran membaca, menulis, dan berhitung (calistung) berbasis gamifikasi dan AI untuk anak usia dini (4–8 tahun). Aplikasi membantu anak belajar secara interaktif melalui suara, animasi, permainan edukatif, serta adaptive learning yang menyesuaikan materi dengan kemampuan anak.
